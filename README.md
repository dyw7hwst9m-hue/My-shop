# ร้านของฉัน (My Shop) - Mobile-first Web Application

เว็บแอปพลิเคชันร้านค้าออนไลน์รูปแบบ Mobile-first ภาษาไทยเต็มรูปแบบ ออกแบบตามหลัก UX/UI ของแอปพลิเคชันมือถือชั้นนำ รองรับทั้งสมาร์ทโฟน iPhone, iPad และคอมพิวเตอร์ทั่วไป

---

## ฟีเจอร์หลัก (Features)

### 👑 ฝั่งเจ้าของร้าน (Store Owner - มีเจ้าของร้านได้ 1 บัญชี)
1. **แดชบอร์ดสรุปยอดขายแบบเรียลไทม์ (Dashboard)**:
   - ยอดขายวันนี้, ยอดขายทั้งหมด, จำนวนออเดอร์, จำนวนลูกค้า
   - กราฟสรุปยอดขายรายวัน
   - สรุปสถิติลูกค้าแบ่งตามช่วงอายุ (13-17, 18-24, 25-34, 35-44, 45+) แสดงจำนวนคนและเปอร์เซ็นต์
   - จำนวนสินค้าที่เปิดขาย / ปิดขาย
2. **จัดการสินค้า (Product Management)**:
   - เพิ่ม / แก้ไข / ลบสินค้า
   - เปลี่ยนชื่อ, ราคา, รูปภาพ, รายละเอียด, หมวดหมู่
   - ปุ่มสลับสถานะ **"เปิดขาย"** / **"ปิดขาย"** ได้ทันที หากปิดขาย ลูกค้าจะไม่สามารถกดสั่งซื้อได้
3. **จัดการหมวดหมู่สินค้า (Categories)**:
   - เพิ่ม, แก้ไข, ลบหมวดหมู่ แสดงจำนวนสินค้าในแต่ละหมวด
4. **จัดการออเดอร์ (Order Management)**:
   - ดูรายการออเดอร์ตามสถานะ (รอชำระเงิน, รอตรวจสอบสลิป, ชำระเงินแล้ว, กำลังเตรียมสินค้า, พร้อมรับสินค้า, สำเร็จ, ยกเลิก)
   - ดูหลักฐานสลิปการโอนเงินของลูกค้าแบบขยายดูรายละเอียด
   - กดยืนยันการชำระเงิน หรือปฏิเสธการชำระเงิน
5. **จัดการลูกค้า & ยืนยันตัวตน (Customer Management)**:
   - ดูรายชื่อลูกค้าทั้งหมด (ชื่อเล่น, อายุ, วันเกิด, วันที่สมัคร, ยอดซื้อรวม, ประวัติสั่งซื้อ)
   - **ดูรูปถ่ายใบหน้ายืนยันตัวตน (Face Verification) ได้เฉพาะเจ้าของร้านเท่านั้น** ปลอดภัยตามมาตรฐานความปลอดภัย
6. **ระบบรีวิว (Reviews)**:
   - ดูคะแนนดาว ความคิดเห็น และข้อความรีวิวจากลูกค้าทั้งหมด

---

### 🛒 ฝั่งลูกค้า (Customers)
1. **สมัครสมาชิก & เข้าสู่ระบบ**:
   - กรอก Email, Password, ชื่อเล่น, อายุ หรือวันเกิด
   - อัปโหลดหรือถ่ายรูปใบหน้าด้วยกล้องมือถือเพื่อยืนยันตัวตน (เก็บแบบ Private)
2. **เลือกซื้อสินค้า**:
   - หน้าร้านสไตล์แอปช้อปปิ้ง แถบหมวดหมู่เลื่อนซ้ายขวา สินค้าแนะนำ สินค้าทั้งหมด
   - ค้นหาสินค้าได้รวดเร็ว
   - ดูรายละเอียดสินค้า คะแนนรีวิว และความคิดเห็น
3. **ตะกร้าสินค้า & ชำระเงิน**:
   - เพิ่ม/ลดจำนวนสินค้า ตรวจสอบยอดรวม
   - ชำระเงินผ่าน QR Code พร้อมเพย์ของร้าน
   - แนบรูปสลิปโอนเงินทันทีหลังสั่งซื้อ หรือแนบภายหลังในหน้าออเดอร์
4. **ติดตามออเดอร์ & รีวิว**:
   - ตรวจสอบสถานะออเดอร์แบบเรียลไทม์
   - เขียนรีวิวให้คะแนนดาวและข้อความเมื่อออเดอร์สำเร็จ

## 🛠️ วิธีเชื่อมต่อและติดตั้ง Firebase (Firebase Setup Guide)

แอปพลิเคชันนี้ออกแบบให้เชื่อมต่อกับ **Firebase** จริง (Authentication, Cloud Firestore, Firebase Storage) และมีระบบ Persistence ในตัว

### ขั้นตอนที่ 1: สร้างโปรเจกต์ใน Firebase Console
1. เข้าไปที่ [Firebase Console](https://console.firebase.google.com/) แล้วคลิก **"Add project"**
2. ตั้งชื่อโปรเจกต์ เช่น `my-shop-thai` แล้วกดสร้างจนเสร็จ

### ขั้นตอนที่ 2: เปิดใช้งาน Authentication
1. เมนูด้านซ้ายเลือก **Build** -> **Authentication**
2. คลิก **Get started**
3. ในแท็บ **Sign-in method** เลือก **Email/Password** -> กด **Enable** -> บันทึก

### ขั้นตอนที่ 3: เปิดใช้งาน Cloud Firestore
1. เมนูด้านซ้ายเลือก **Build** -> **Firestore Database**
2. คลิก **Create database** -> เลือกโหมดการทำงานและ Region (เช่น `asia-southeast1` หรือ `us-central1`)
3. ในแท็บ **Rules** นำเนื้อหาจากไฟล์ `firestore.rules` ในโปรเจกต์นี้ไปวาง แล้วกด **Publish**

### ขั้นตอนที่ 4: เปิดใช้งาน Firebase Storage
1. เมนูด้านซ้ายเลือก **Build** -> **Storage**
2. คลิก **Get started** -> เลือก Region แล้วกดสร้าง
3. ในแท็บ **Rules** นำเนื้อหาจากไฟล์ `storage.rules` ในโปรเจกต์นี้ไปวาง แล้วกด **Publish**

### ขั้นตอนที่ 5: นำ Config มาใส่ในโปรเจกต์
1. ในหน้า **Project settings** (ไอคอนฟันเฟือง) -> เลื่อนลงมาที่หัวข้อ **Your apps** -> คลิกไอคอนเว็บ `</>`
2. ตั้งชื่อ App แล้วกด Register
3. คัดลอกค่า `firebaseConfig` มาใส่ในไฟล์ `.env` หรือสามารถกดใส่ในหน้า **ตั้งค่า (Settings)** ภายในตัวแอปได้ทันที:

```env
VITE_FIREBASE_API_KEY="AIzaSy..."
VITE_FIREBASE_AUTH_DOMAIN="your-app.firebaseapp.com"
VITE_FIREBASE_PROJECT_ID="your-app"
VITE_FIREBASE_STORAGE_BUCKET="your-app.appspot.com"
VITE_FIREBASE_MESSAGING_SENDER_ID="123456789"
VITE_FIREBASE_APP_ID="1:123456789:web:abcdef"
```

## โครงสร้างความปลอดภัย (Security Rules Overview)
- **สิทธิ์ลูกค้า**: อ่านสินค้าและหมวดหมู่ได้, เข้าถึงและแก้ไขเฉพาะข้อมูลโปรไฟล์และออเดอร์ของตนเองเท่านั้น, ห้ามแก้ไขสถานะการชำระเงิน
- **สิทธิ์เจ้าของร้าน**: จัดการสินค้า, ออเดอร์, ยืนยันสลิป, ดูข้อมูลลูกค้าและภาพถ่ายใบหน้ายืนยันตัวตนได้ทั้งหมด
